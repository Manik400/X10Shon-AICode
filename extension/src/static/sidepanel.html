Local-First Agent

How to use
  1. Open your Job Hunt list (or any job page) in this tab.
  2. Pick a request below (or type your own) and press Run.
  3. The agent opens each job in a new tab of this window, fills it from your profile and resume, submits and moves on. A cursor and banner show what it is doing; you can keep using other tabs.
  4. Results: Open dashboard (confirmed, waiting, skipped and why).

When it stops
  • Sign-in page (e.g. Workday): the tab stays open; sign in there and the agent continues on its own.
  • A question it has no answer for: the field is left empty in that tab. Fill it in yourself and press Resume: the agent continues on that same page and keeps what you typed.
  • Pause all stops everything; Resume continues. Already-submitted jobs are never applied to twice.
